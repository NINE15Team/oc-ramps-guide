OC Ramps theme overview

How the OC Ramps storefront is built, and where to go to change it. Written for the people who run the store day to day and the developers who maintain it.

What this site is

OC Ramps sells skate ramp kits, obstacles, surfaces, paint and apparel, and runs custom builds, rentals, events and lessons. The storefront runs on Shopify using Shopify's Horizon theme, customized by Nine15. Almost every page is built in the Shopify theme editor from sections and blocks, so most content changes need no code.

Key features

  • Shared product stories. The lower half of every product page reads a PDP Profile record, so one record can feed many products. See Product page content.
  • Free-shipping card by product. The free-shipping message only shows on the products picked in theme settings. See Free-shipping claim.
  • Tag-driven blogs. DIY Plans, Skate Library and the Our Work story library are sorted by exact article tags. See How blog tags work.
  • Featured story per tab. Each Our Work tab has its own hand-picked featured story. See Our Work stories.
  • Buyer's Guides hub with decision cards and a guide sequence, all edited in the theme editor. See Buyer's Guides.
  • Skate Glossary and team rider profiles powered by metaobjects. See Glossary & rider profiles.
  • Native Shopify cart drawer with upgrades, recommendations and terms acceptance (no cart app).
  • Apps for reviews (Okendo), email/SMS (Klaviyo), chat (Tidio), cookie consent (Consentmo), session recording (Microsoft Clarity) and more. See Apps & integrations.

Plain-English terms

A handful of Shopify words come up everywhere. Here is what they mean on this site.

The building blocks

TermWhat it means

TemplateA page recipe, such as Product or Buyer's Guide article. Many pages can share one template. See Template map.
Section / blockA visible area of a page, and the smaller pieces inside it, in the theme editor.

Using the theme editor

The theme editor controls layout, section order, colours and most homepage and landing page content.

Open the right theme

  1. Go to Online Store → Themes.
  2. On the live theme (OC-Ramps/QA), click Customize. To work on a copy first, use ⋯ → Duplicate and customize the copy.
  3. Use the page selector at the top to pick Home, Product, Collection, a blog or a specific page template.

Edit a section

  1. Select a section in the left panel. Its settings open on the right.
  2. Blocks inside it (slides, text, buttons, cards) can be added, reordered by dragging or hidden with the eye icon.
  3. Preview desktop and phone with the device icons at the top, then Save.

Know the scope

Editing a template changes every page that uses it. For example, editing the product template changes all product pages. Duplicate the theme before large layout changes, and check which template a page uses in the Template map.

Settings firstColours come from colour schemes, text sizes come from the theme's type presets (H1–H6, Paragraph), and spacing comes from padding and gap settings. Use those instead of asking for one-off CSS, so future edits keep working in the editor.

Edit and preview an unpublished page

Build or change a page while it is hidden from customers, check it on desktop and phone, then make it visible. Nothing here changes the live site until the last step.

Create the page hidden

  1. Go to Online Store → Pages and click Add page (or open an existing hidden page).
  2. Enter the Title and any Content.
  3. In the right column, under Visibility, choose Hidden.
  4. Under Template, pick the template for this kind of page from the Template map.
  5. Under Search engine listing, check the URL and description, then click Save.
Hidden meansCustomers who open the link get a “page not found” message, and the page is left out of search and the sitemap. Staff signed in to Shopify Admin can still preview it.

Preview it

  1. At the top of the page editor, click Preview. The page opens in a new tab for you only.
  2. Check it on desktop, then narrow the window (or open the same preview on your phone while signed in) to check the phone layout.
  3. Click every button and link on the page.

Edit its layout in the theme editor

  1. In the page editor, click the eye icon next to Template. The theme editor opens on that template.
  2. Edit sections and blocks, preview desktop and phone with the device icons, then click Save.
  3. Go back to the page editor and click Preview again to see the result.
Know the scopeTemplate changes apply to every page that uses the same template, including visible ones. If the page needs a different layout from the others, ask a developer for its own template, or practise on a duplicated theme first (Online Store → Themes → ⋯ → Duplicate, then Customize the copy). A duplicated theme never affects the live site until it is published.

Make it live

  1. In the page editor, under Visibility, choose Visible (or set a date to publish it later), then click Save.
  2. Add a menu link if visitors need one (Content → Menus).
  3. Open the page on ocramps.com in a private window to confirm customers can see it.

  2. Otherwise, the first of the product's collections that has a custom.pdp_profile.

Free-shipping claim

The free-shipping card on product pages only shows on products picked as eligible. Every other product hides it and keeps its other shipping cards.

How it works

  • The list lives in Theme settings → Free-shipping claim → Products eligible for free shipping (up to 50 products).
  • On a product in the list, the Shipping card shows as written in its PDP Profile.
  • On a product not in the list, the Shipping card hides if it mentions free shipping. Cards that say something else (for example "Confirm surface-sheet shipping") still show.
  • If the free-shipping card was the only card, the whole Shipping section hides, so there is never an empty box.
  • Leaving the list empty shows the card on every product.

Add or remove an eligible product

  1. Open the theme editor, then Theme settings → Free-shipping claim.
  2. Click Select products, tick or untick the product, then save.
  3. Open the product page and check the Shipping card.
Current listThe list holds the 32 full-size ramps from the approved eligibility map (October 2026). Surface sheets (GatorSkins, Skatelite), paint, apparel, fingerboards, rails, accessories and the gift card are not eligible.
WordingThe card's wording comes from shipping_card_1_title and shipping_card_1_body in each product's PDP Profile. Change the words there, not in the theme.

How blog tags work

Article tags decide which hub, listing, filter or badge an article appears in. Get the tag right and everything else fills itself.

The one rule that matters most

Tags are exact-matchThe site looks for the tag character for character. A wrong letter, a space instead of an underscore, the wrong capital or a trailing space means the article publishes but does not appear where you expect. There is no warning.

When something does not show up, check the tag first. Copy tags from the tables in these docs, or from an existing article in the same category.

The tag styles

AreaTag styleExample
DIY PlansLowercase, double underscore before planmini_ramp__plan
Skate LibraryReadable tag matching a filter tabFlat Ground
Our Work storiesPrefixed tags for story type and project type_story_type__Builds, _our_work__Home & Private Builds
Buyer's GuidesNo tags needed. The hub is edited in the theme editor.See Buyer's Guides

Style A: double-underscore tags (DIY Plans)

Format: category_name__plan. Anatomy of quarter_pipe__plan:

PartValueWhat it does
Left sidequarter_pipeThe category name. Underscores become spaces on screen, so this reads "Quarter Pipe".
Separator__Two underscores, not one. This splits the category from the type.
Right sideplanThe type word. It is pluralized on screen, so it reads "Plans".
Result on screenQuarter Pipe Plans
  • All lowercase, always. Words separated by single underscores. No spaces anywhere.
  • Correct: quarter_pipe__plan
  • Wrong: Quarter Pipe Plan, quarter_pipe_plan, quarter-pipe__plan, Quarter_Pipe__Plan

Style B: readable tags (Skate Library)

  • Normal words with spaces and capitals, typed exactly as the tab label reads.
  • Correct: Flat Ground
  • Avoid: flat ground, Flat_Ground, flatground. The tab may still match some of these, but the tag is shown on cards exactly as typed, so keep the readable form.

Style C: prefixed tags (Our Work)

A fixed prefix, two underscores, then the label: _story_type__Builds or _our_work__Business Skateparks. Keep the leading underscore, the capitals, the spaces and the &.

RememberThe theme editor cannot create tags. It can only point at tags that already exist on articles. Every tag is created and edited in Shopify Admin, on the article itself. See Where each thing is edited.

  • An article can carry two tags. It then appears under both cards and counts toward both numbers.

Speed & scripts

What the theme does to keep pages fast, and what to watch when adding apps.

What the theme already does

  • First-screen images load first. Images lower on the page, in closed menus or inside articles load when needed.
  • Images are served at the size they are shown.
  • Chat (Tidio) and Clarity start on the visitor's first interaction.
  • YouTube players and Affirm load only when needed.
  • App scripts used on one page only (Instafeed, the Enorm gallery) load only on that page.

What slows the site most today

The Google tags set up in Settings → Customer events and the Google & YouTube app. Each page loads several Google tags, some twice. Keep only the tags you use, and make sure each loads once.

When adding an appCheck PageSpeed (pagespeed.web.dev) on the homepage and a product page before and after. Scores move a few points between runs, so compare two or three runs.

SEO & content best practices

A short checklist for every page, product and article.

  • Write a clear, unique title and a useful description under Search engine listing.
  • Use one main heading (H1) and meaningful subheadings.
  • Keep URL handles short and stable. When changing one, add a URL redirect.
  • Add descriptive alt text to every image, and upload photos at least as wide as they are shown (1600 px for full-width article photos).
  • Link related pages and products, and check every button after editing.

Structured data the theme adds

Product pages publish the price of the selected option, availability, brand and review rating (from Okendo). The store-wide organization data includes the return policy link. The official social profiles are added there too once T-27 is published Waiting. You do not need an SEO app for these.

Redirects

Add redirects in Content → Menus → URL redirects. Redirect to the exact matching page, never to the homepage.

Users & permissions

Give each person their own account with only the access they need.

  1. The store owner opens Settings → Users.
  2. Invite by email and grant only the permissions needed. A content editor usually needs products, content, files and online store.
  3. Review staff and collaborator accounts after each project and remove the ones no longer needed.
SecurityRequire two-step authentication. Never share one login. Never put passwords or API keys in these docs, GitHub or email.

Release workflow

  1. Duplicate the live theme as a dated backup.
  2. Make each fix as its own commit, titled with its tracker ID (for example T-79: …).
  3. Push the branch to a review theme and check desktop and phone against live.
  4. Merge into QA only after approval. The live theme updates from QA through the GitHub integration.

Rules that avoid breakage

  • Theme editor saves write to the JSON templates. Pull the latest theme files before pushing, so merchant edits are not overwritten.
  • Shopify rejects template JSON over 512 KB. templates/index.json is kept minified for this reason.
  • Use settings (colour schemes, type presets, padding, gap) before CSS. Never write CSS that overrides an editor setting.
  • Use Shopify image files and image settings, not images uploaded into the theme.

Routine maintenance

A light routine that keeps the store healthy.

Monthly

  • Click through home, a collection, a product, cart and checkout on phone and desktop.
  • Check mega menu cards and footer links after products or collections are removed.
  • Check the Okendo, Klaviyo and Tidio dashboards for errors.

Quarterly

  • Duplicate the live theme as a dated backup.
  • Run PageSpeed on home, a collection and a product page.
  • Review staff accounts, unused apps and the Google tags in Customer events.
  • Review the Free-shipping claim list against the current shipping policy.

Before a campaign

  • Build landing pages on a duplicated template, preview, then publish.
  • Update the hero slides, mega menu cards and featured stories.
BackupsA theme duplicate protects theme code and settings only. Export products and content separately with Shopify's export tools or an approved backup app.
